### Rules
- User can add unlimited intermediate stops with the "+ Add Stop" button

- Stats card shows total distance, duration, calories
- Save to history with mode = 'custom'

### Goal/Pace
- The goal (calories/minutes/km) is INFORMATIONAL in this mode (the user chose their path)
- Pace selector still works to calculate accurate calories
- Show note: "This is your custom path. Stats are calculated based on your chosen pace."

## IMPROVEMENT 3 - Better Google Maps / Apple Maps / Waze integration

Currently, when users click "Start Navigation", the external maps apps don't respect the generated route. Fix this by:

### For Loop mode
Google Maps and Apple Maps don't handle loops well because start = end. Solution:
- DON'T directly send to Google Maps with start = end (it shows "you're at destination")
- INSTEAD, decompose the loop into multiple segments
- Take the route's GeoJSON LineString from OpenRouteService
- Extract 4-6 evenly-distributed waypoints along the loop
- Open Google Maps with these waypoints (excluding the duplicate start/end)
- Format: https://www.google.com/maps/dir/?api=1&origin=LAT,LNG&destination=LAT,LNG&travelmode=walking&waypoints=LAT1,LNG1|LAT2,LNG2|LAT3,LNG3|LAT4,LNG4
- Use a final destination different from start: pick the second-to-last waypoint as destination, and start as origin

### For A->B modes (direct and with detour)
To force external maps to follow OUR generated route (not their optimal one):
- Extract 6-8 waypoints along the OpenRouteService route (evenly distributed)
- Pass ALL waypoints to Google Maps URL
- Google Maps accepts up to 10 waypoints on web
- This significantly increases route fidelity vs just sending start + end

### For Custom Route mode
- Use the user-defined waypoints directly (already perfect)

### Apple Maps limitations
Apple Maps URL scheme doesn't support multiple waypoints well. For Apple Maps:
- Show a warning message: "Apple Maps may use its own optimal route. For best results with multi-waypoint routes, use Google Maps."
- Still provide the Apple Maps button as fallback

### Waze
- Waze doesn't support waypoints
- Only show Waze for simple A->B direct mode
- Hide Waze button for Loop, A->B with detour, and Custom modes
- For these modes, only show Google Maps + Apple Maps

### UI for navigation choice
When user clicks "Start Navigation":
- Show a bottom sheet with available options
- Disabled buttons (with tooltip) for incompatible combos (e.g., Waze for Loop)
- Recommendation badge: "Recommended" on Google Maps for routes with waypoints

### Helper text
Below the "Start Navigation" button, add a small note:
"Note: External apps may slightly adjust the route. For maximum accuracy, follow the in-app map."
