Fix two bugs in the existing FitConnect app.

## BUG 1 - Horizontal overflow on the right side

Some panels and cards overflow horizontally, causing an unwanted 
horizontal scroll on both mobile and desktop. Fix this by:

1. Add `overflow-x: hidden` to both `html` and `body` elements 
   in the global CSS file
2. Review all top-level page containers and ensure they use:
   - `max-width: 100%`
   - `box-sizing: border-box`
   - No `width: 100vw` (use `width: 100%` instead)
3. Check specifically these sections that are likely overflowing:
   - The Track tab cards (meal log, workout log)
   - The Walk tab form panel
   - The Coach tab message bubbles (long messages may overflow)
   - The onboarding screens
4. For text/buttons that might overflow, add:
   - `word-wrap: break-word`
   - `overflow-wrap: anywhere` on long text
5. Test on viewport widths: 375px (mobile), 768px (tablet), 1440px (desktop)
6. Ensure no element creates horizontal scroll on any page
