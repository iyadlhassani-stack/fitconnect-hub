- Make it a fully functional PWA (manifest.json + service worker for offline + installable on mobile)

## APP STRUCTURE - 4 TABS BOTTOM NAVIGATION

### Tab 1 - HOME 🏠
Personalized dashboard:
- Greeting with name + current time of day ("Good morning Iyad")
- Streak counter card (orange flame icon + days, "Don't break the chain!")
- Today's coach check-in card (latest unread proactive message from AI)
- Quick stats: today's calories vs target, protein, workouts logged
- "Quick Actions": [Log Meal] [Log Workout] [Log Weight] [Generate Walk]
- Active goals progress bars

### Tab 2 - COACH 🤖 (the centerpiece feature)
Chat interface with the AI coach:
- Header: coach avatar + name + "online" indicator
- Message thread (user messages on right blue bubbles, AI messages on left grey bubbles)
- Proactive check-in messages appear automatically when scheduled times hit
- Bottom: text input + send button
- Side menu: "Settings" (edit check-in times), "History", "Goals"

The AI coach uses Claude API with system prompt:
"You are a personal fitness and nutrition coach for [user_name]. Their goal is [goal]. Their current weight is [weight]kg, target is [target]kg, on a daily calorie target of [calories] kcal and [protein]g protein. They follow a [diet] diet with allergies: [allergies]. Be warm, motivating, direct, and use 'tu' if French. Use their full conversation history to remember context. When they share what they ate, ask follow-up questions to help log macros. When they share a workout, congratulate and adapt advice. Be proactive: ask check-in questions, suggest walks if they have a calorie deficit to fill, remind about hydration. Keep responses short (2-4 sentences) like a real coach texting."

The check-in system:
- A serverless function (or scheduled worker) runs every minute
- For each user, checks if it's their check-in time AND no check-in done today for that slot
- Generates a contextual message via Claude API
- Saves to coach_messages table
- Sends OneSignal push notification + email (if push fails)

Check-in templates (Claude generates variations):
- 8AM (morning): "How did you sleep? What's the plan today?"
- 1PM (lunch): "What did you have for lunch? How are you feeling?"
- 6PM (evening): "Workout planned today? Need a quick walk to hit your goal?"
- 9PM (night): "Quick wrap-up: how did the day go? Did you hit your protein target?"

After 2 days of inactivity: "Hey, you ok? Haven't heard from you, here if you need anything."

When user has calorie deficit > 200 in evening check-in, AI proactively suggests:
"You still have 300 kcal to burn today. A 35-min walk would do it. Want me to generate a route?"
[button: Generate Walk] -> opens Walk tab pre-filled with kcal target

### Tab 3 - TRACK 📊
Tracking section with sub-tabs:

3a - Today
- Add meal: form with name, calories, protein, carbs, fat (or AI-assisted: "describe your meal" -> Claude estimates macros)
- Add workout: name, duration, type, calories burned
- Add weight: simple input
- Add water (quick +250ml buttons)
- Visual: macro rings showing progress vs target

3b - History
- Calendar view showing logged days
- Tap day to see details
- Weekly/monthly graph: weight evolution, calorie average, workout count

3c - Photos
- Upload progress photo (saves to Supabase Storage)
- Timeline view chronological
- Compare mode: select 2 photos side by side

### Tab 4 - WALK 🗺️
The kcal-based route generator:

Form:
- Starting point (text input + "Use my location" button using Geolocation API)
- Mode selector: [Loop] (only mode in MVP, mention "Point A to Point B coming soon")
- Target type: [Calories] [Minutes] [Distance]
- Target value: number input (e.g., 300 kcal, 45 min, 5 km)
- Walking pace: Slow (4 km/h) / Normal (5 km/h) / Fast (6 km/h)

When user submits:
1. Convert target to distance:
   - If calories: distance_km = (calories / (MET * weight)) * speed_kmh, where MET depends on pace
   - If minutes: distance_km = (minutes / 60) * speed_kmh
   - If distance: use directly
2. Call OpenRouteService /v2/directions/foot-walking with options.round_trip parameter:
   - length: target distance in meters
   - points: 3 (number of waypoints)
   - seed: random
3. Generate 3 different route proposals (call API 3 times with different seeds)
4. Display each as a card with: small map preview (Leaflet), distance, duration, estimated calories, "Start" button
5. When user taps "Start": full screen map with route + start tracking
6. After completion: save to walking_routes table, send congrats message via coach to chat

Calorie calculation formula:
calories = MET * weight_kg * (duration_minutes / 60)
MET values: slow=3, normal=3.5, fast=4.5
